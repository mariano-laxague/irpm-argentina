IRPM: Índice de Riesgo Político del Mercado

¿Qué es el IRPM?

Señales de mercado para leer el contexto argentino

IRPM · Base 100 = dic 2023
93.0
↓ 8.5 pts vs. mes anterior Actualizado 2026-11-04

El IRPM resume cómo están valuando los mercados las condiciones financieras argentinas vinculadas al escenario político y económico. Combina mercado cambiario, deuda soberana y volatilidad accionaria en una sola lectura comparable en el tiempo.

Cómo leerlo: 100 es la referencia de diciembre de 2023. Por encima de 100, las señales incluidas están, en conjunto, más favorables que esa base; por debajo, muestran mayor presión o fragilidad. El cambio mensual muestra si esa lectura se está fortaleciendo o deteriorando.

Hoy: 93.0, levemente por encima de la base Sube si mejoran las tres señales; baja si se tensionan Sirve para detectar cambios de clima financiero

No predice elecciones ni prueba por sí solo la causa de un movimiento: aporta una señal de mercado que conviene contrastar con el contexto.

Construcción y evidencia
Metodología
Para quienes quieren entender cómo se construye el índice
IRPM(t) = 100 + (0.35·z₁ + 0.40·z₂ + 0.25·z₃ − z_baseline) × 10
// Baseline = 11 dic 2023 → IRPM = 100
// z₁ = Mercado cambiario (MEP + ROFEX) · 35%
// z₂ = Deuda soberana (GD30, AL30, EMBI, law spread) · 40%
// z₃ = Semi-vol realizada (YPFD/GGAL/PAMP/TECO2) · 25%

Cada z-score mide cuántos desvíos estándar se aleja la señal de su media rolling de 252 ruedas. Los tres se combinan y se reescalan como distancia respecto de un baseline convencional.

El EMBI (riesgo país) está incluido como uno de varios inputs de la capa de deuda soberana, no como el único indicador. Esto permite capturar divergencias: el riesgo país puede estar tranquilo mientras el mercado cambiario muestra presión, o viceversa.

Una grilla de 14 combinaciones mostró estabilidad de las fechas extremas, con variaciones de magnitud de hasta ~5,5 puntos. Es evidencia de robustez acotada, no validación del constructo ni de pesos óptimos. Ver metodología experimental →
